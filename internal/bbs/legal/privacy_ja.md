# gobot 匿名掲示板 プライバシーポリシー

1. 収集・保持する情報
gobot は本機能の提供および不正対策のため、以下の情報をデータベースに保存します。
- 同意記録: Discord ユーザー ID、同意したポリシーバージョン、同意日時
- 掲示板データ: 投稿内容、表示名、トリップ、日替わり板別 ID、ワッチョイ（SLIP）
- 監査用識別情報: 投稿者の Discord ユーザー ID、および秘密鍵による HMAC-SHA256 ハッシュ（モデレーション用匿名ハッシュ）

2. 匿名性の保護とギルド管理者への非開示
- 掲示板上の表示には日替わり・板別の匿名 ID のみが使用され、他の利用者から Discord ユーザー ID やアカウント名は見えません。
- ギルド管理者がモデレーション機能を利用する場合でも、生 Discord ユーザー ID は一切開示されません。ギルド管理者は匿名モデレーションハッシュ単位での「あぼーん」やローカルアク禁のみを実行できます。

3. 運営による監査情報の利用目的
- サーバー側で保持する投稿者の Discord ユーザー ID は、通常時は閲覧されません。
- 通報への対応、重大な規約違反・荒らし行為に対するグローバルアクセス禁止措置、または法令・プロバイダ責任制限法等に基づく適法な開示請求への対応に限り、gobot 運営が監査ログとして照会する場合があります。

4. 外部サーバーへの配信（グローバル板）
- グローバルカテゴリ配下の板への投稿は、当該板を購読している他の Discord サーバーにも同一の匿名形式で同期配信されます。
- メディア URL を含む投稿は、Discord のメディアプレビュー機構を通じて表示されます。第三者サーバー上の外部リンク先の閲覧には各サービスのプライバシーポリシーが適用されます。

5. 同意の撤回
- 利用者は `/bbs policy` コマンドからいつでも同意を撤回できます。撤回後は新規投稿や通知購読が停止されます（既存の匿名投稿データ自体は掲示板の整合性維持のため保持され、問題がある場合は通報・モデレーションにより「あぼーん」処理されます）。
