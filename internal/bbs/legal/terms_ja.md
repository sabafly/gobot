# gobot 匿名掲示板システム 利用規約

第1条（適用およびオプトイン）
1. 本規約は、Discord ボット「gobot」が提供する匿名掲示板機能（以下「本機能」といいます）の利用条件を定めるものです。
2. 本機能はオプトイン形式であり、サーバー（ギルド）管理者が本機能を有効化し、かつ利用者が本規約・ガイドライン・プライバシーポリシーに同意した場合にのみ利用できます。

第2条（掲示板の区分と責任範囲）
1. ギルドローカルカテゴリの板は、当該サーバーの管理者が作成・管理・モデレーションを行います。
2. グローバルカテゴリの板は、gobot 運営が作成・管理・モデレーションを行い、購読している複数の Discord サーバー間でスレッドおよびレスが共有・同期されます。
3. グローバル板へ投稿された内容は、当該板を購読するすべてのサーバーに配信・表示されることをあらかじめ承諾するものとします。

第3条（禁止事項）
利用者は、コミュニティガイドラインおよび Discord 利用規約・コミュニティガイドラインに違反する投稿（違法行為の助長、児童性的搾取、著作権侵害、個人情報・プライバシーの無断公開、誹謗中傷、過度なスパム・連投等）を行ってはなりません。

第4条（モデレーションおよび免責）
1. ギルド管理者（ギルドローカル板）または gobot 運営（グローバル板）は、規約やガイドラインに違反すると判断した投稿を予告なく削除（あぼーん）、スレッドのロック・アーカイブ、または利用制限（アクセス禁止）を行うことができます。
2. 本機能は現状有姿で提供され、外部サーバー障害や Discord API 制限等による遅延・欠損・データ消失について、gobot 運営は故意または重過失がある場合を除き責任を負いません。

第5条（規約の変更および同意の撤回）
1. gobot 運営は、必要に応じて本規約のバージョンを更新することがあります。更新後は再同意が完了するまで新規書き込み等の操作が制限されます。
2. 利用者はいつでもコマンドから同意を撤回し、本機能の新規利用を停止することができます。
