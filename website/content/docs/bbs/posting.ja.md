匿名掲示板でのスレッド作成・書き込み・匿名 ID・ワッチョイ（SLIP）・キャップなどの投稿仕様をまとめています。

## スレッド作成とレス投稿

1. 板のコントロールパネルまたはスレッド内のボタン（「新規スレッド」「レスを書く」「返信」など）を押すと投稿モーダルが開きます。
2. 初回操作時に未同意の場合は、[BBS 利用規約](/bbs/terms/)・[ガイドライン](/bbs/guidelines/)・[プライバシーポリシー](/bbs/privacy/) の確認と同意画面が表示されます。
3. スレッド内の「ウォッチ」ボタンで新着レスの DM 通知をオン／オフできます。

## 匿名 ID とトリップ

- **日替わり板別 ID**: 秘密鍵による HMAC-SHA256 と JST（日本標準時）の日付・板 ID から生成される匿名 ID が付与されます。Discord のユーザー名やユーザー ID は他の利用者には表示されません。
- **トリップ**: 名前欄に `#鍵文字列` を含めることで、本人証明用のトリップを生成できます。
- **レスアンカーとメディア**: 本文中の `>>1` のようなアンカー（1投稿あたり最大10件）や画像・メディア URL（最大10件）に対応しています。

## ワッチョイ（SLIP）

板の設定またはスレッド先頭での指定により、投稿時の匿名属性に基づく **ワッチョイ（SLIP）** を表示できます。

| モード | 表示内容 |
| --- | --- |
| `none` | ワッチョイを表示しません。 |
| `vvv` | 投稿時の匿名属性（アカウント歴・バッジ・VC 状態・サーバー規模帯など、個人やサーバー名を直接特定しない特徴）や日時に基づくニックネームを表示します。 |
| `vvvvv` | `vvv` のニックネームに加え、ユーザー ID 由来の固定 4 文字とニックネーム・表示名を加味した 4 文字の計 8 文字コード（コロコロ、`abcd-efgh` 形式）を表示します。 |

スレッド作成時に `!slip:vvv`・`!slip:vvvvv`・`!extend` などの指定が有効な場合、スレッド単位で SLIP 表示が適用されます。

## キャップ（Cap）

運営または設定ファイルで許可された利用者は、投稿モーダルのキャップ選択から専用のキャップ表示名で書き込むことができます。フェデレーション先のグローバル板では、連携先（Origin）側で許可されているキャップ一覧が自動的に取得されます。
