# gobot 匿名掲示板 プライバシーポリシー

gobot 運営（以下「運営」といいます）は、Discord ボット「gobot」の匿名掲示板機能（以下「本機能」といいます）における利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

## 1. 収集・保持する情報

運営は、本機能の提供、維持および不正対策のため、以下の情報をデータベースに保存します。

- **同意記録**: Discord ユーザー ID、同意したポリシーバージョン、同意日時
- **掲示板データ**: 投稿内容、表示名、トリップ、日替わり板別 ID、ワッチョイ（SLIP）、投稿日時
- **通知購読記録**: スレッド通知を購読した利用者の Discord ユーザー ID、表示言語ロケール、登録日時
- **通報記録**: 通報者の Discord ユーザー ID、対象投稿・スレッド ID、通報理由、対応状況
- **監査用識別情報**: 投稿者の Discord ユーザー ID、および秘密鍵による HMAC-SHA256 ハッシュ（モデレーション用匿名ハッシュ）

## 2. 利用目的

収集した情報は、以下の目的の範囲内でのみ利用します。

1. 本機能の提供、維持、改善およびスレッド通知（DM 通知）の配信
2. 利用規約およびコミュニティガイドライン違反行為の調査、モデレーションおよび不正アクセス・荒らし行為の防止
3. 通報への対応およびアクセス禁止措置（ローカルアク禁・グローバルアク禁）の執行
4. 法令に基づく照会・開示請求への対応および紛争解決

## 3. 匿名性の保護とギルド管理者への非開示

1. 掲示板上の表示には日替わり・板別の匿名 ID のみが使用され、他の利用者から Discord ユーザー ID やアカウント名は閲覧できません。ただし、ワッチョイ（SLIP）が有効な板または `!slip:vvv` / `!slip:vvvvv` / `!extend` が指定されたスレッドで ID 非表示がオフの場合、投稿時の Discord 属性（アカウント歴・バッジ・VC状態・サーバー規模帯など、生のアカウント名やサーバー名を特定しない範囲の特徴）や日時に基づくニックネームが公開表示されます。さらに `vvvvv` の場合は、ユーザー ID から秘密鍵で導出された固定 4 文字と、ニックネーム・表示名を加味した 4 文字の計 8 文字コード（コロコロ、`abcd-efgh` 形式）が併せて公開表示されます。
2. ギルド管理者がモデレーション機能を利用する場合であっても、生の Discord ユーザー ID は一切開示されません。ギルド管理者はギルドローカル板において、匿名モデレーションハッシュ単位での「あぼーん」およびローカルアク禁のみを実行できます。

## 4. 運営による監査情報の利用および第三者提供

1. サーバー側で保持する投稿者の Discord ユーザー ID は、通常時は閲覧されません。
2. 運営は、次のいずれかに該当する場合を除き、利用者情報を第三者に提供しません。
   - **グローバル板への同期配信**: グローバルカテゴリ配下の板への投稿データは、当該板を購読している他の Discord サーバーへ同一の匿名形式で同期配信されます。同期先サーバーにおける当該データの保存、転載、削除または管理状況について、運営は一切の責任を負いません。
   - **法令等に基づく開示**: 裁判所の令状、捜査関係事項照会、情報流通プラットフォーム対処法（旧プロバイダ責任制限法）に基づく適法な発信者情報開示請求・開示命令、その他法令に基づく要請がある場合。なお、運営が適法と判断して行った開示により利用者に損害が生じた場合であっても、運営に故意または重過失がある場合を除き責任を負いません。
   - **生命・財産の保護**: 人の生命、身体または財産の保護のために緊急の必要があり、本人の同意を得ることが困難である場合。
3. 重大な規約違反・荒らし行為に対するグローバルアク禁措置および通報対応に限り、運営が監査ログとして投稿者の Discord ユーザー ID を照会する場合があります。

## 5. 外部リンク、メディアプレビューおよび Discord の仕様

1. メディア URL を含む投稿は、Discord のメディアプレビュー機構を通じて表示されます。外部リンク先の閲覧および外部サービスの利用には、各サービス提供者のプライバシーポリシーが適用され、これらに起因する情報漏えい、マルウェア感染その他の損害について運営は一切の責任を負いません。
2. 本機能は Discord プラットフォーム上で動作するため、Discord Inc. によるデータ収集・処理については Discord のプライバシーポリシーが適用されます。

## 6. 安全管理措置および免責

1. 運営は、データベースへのアクセス制御および秘密鍵によるハッシュ化（HMAC-SHA256）等により、合理的な範囲で利用者情報の漏えい、滅失または毀損の防止に努めます。ただし、インターネット通信および電子データ管理の性質上、完全な安全性を保証するものではなく、不正アクセス、サイバー攻撃、ソフトウェアの脆弱性、ハードウェア障害その他運営の責めに帰さない事由により生じた情報漏えい・消失等について、運営は一切の責任を負いません。
2. 収集した情報は、本機能の提供および不正対策・法令対応に必要な期間保持します。ただし、運営はデータの永続的な保持を保証せず、システム障害や仕様変更等によりデータが消失した場合であっても一切の責任を負いません。

## 7. 同意の撤回およびデータ削除

1. 利用者は `/bbs policy` コマンドからいつでも本ポリシーへの同意を撤回できます。
2. 同意撤回時には、同意記録および有効なスレッド通知購読記録（DM 通知設定）が直ちに削除され、以降の新規投稿・通知購読・DM 通知・通報等の操作は停止されます。
3. 前項にかかわらず、既存の匿名投稿データ自体は掲示板の整合性維持のため保持されます（問題がある場合は通報・モデレーションにより「あぼーん」処理されます）。また、不正行為の再発防止、アクセス禁止措置の維持および法令に基づく開示請求への対応のため、監査用識別情報および通報記録は必要な範囲で引き続き保持される場合があります。

2. 本ポリシーに関するお問い合わせや開示等のご請求は、サポートサーバーにてご連絡ください。
